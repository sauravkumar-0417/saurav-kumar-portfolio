# Saurav Kumar Portfolio

A dark, orange-accented personal portfolio built with plain HTML, CSS and JavaScript.

## Upload to GitHub
Upload the contents of this folder to your GitHub repository. Keep `index.html` in the repository root.

## Deploy with Vercel
Import the GitHub repository into Vercel. Framework preset can be `Other`; no build command is required.

## Local preview
Open `index.html` in a browser. Certificate PDF/image previews use the relative paths in `assets/certificates/`.

## Note
The education date `2023 — 2029` is preserved exactly as it appeared in the supplied CV and marked with an asterisk on the site.
